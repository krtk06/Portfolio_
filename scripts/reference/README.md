# Reference artwork

Source images for the particle-field figures. Convert each one to a sampling
grid with `scripts/reference-to-grid.py`.

- `mangrove.png` — supplied mangrove/dryad drawing; source for
  `src/content/reference.js` (Projects figure).
- `knot-source.png` — supplied interlocking-knot reference, with its yellow
  background.
- `knot-mark.png` — the knot's white mark on transparency, cropped from the
  reference and stripped of the background; source for
  `src/content/reference-knot.js` (hero figure). The field tints it brand yellow
  in `shapes.js`.
